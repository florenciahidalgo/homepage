Sales Performance Analysis

An exploratory data analysis project focused on evaluating sales performance and identifying the main drivers of revenue over a one-month period.



Description

This project integrates and analyzes multiple data sources to evaluate sales performance over a one-month period. The analysis combines information about products, sellers and transaction records to generate actionable insights and support business decision-making.

The analysis addresses key business questions such as identifying the best-selling products by units sold, determining which products generated the highest revenue and evaluating seller performance to identify the top seller of the month.

The project also analyzes sales trends over time to identify variations in daily sales and better understand the behavior of sales throughout the month.

The data was integrated from three different sources: an SQLite database containing product information, an Excel file containing seller information and a CSV file containing the monthly transaction records.

The analysis was performed using Python, with Pandas for data manipulation and exploratory analysis, NumPy for numerical operations, and Matplotlib and Seaborn for data visualization.

Data Center Stranded Capacity

A data-driven approach to estimate stranded capacity in data centers and identify opportunities to improve infrastructure utilization and reduce energy waste.



Description

Data centers require significant amounts of infrastructure and energy to operate. However, part of their available capacity may remain underutilized due to infrastructure constraints, operational limitations or mismatches between different components of the facility.

This project explores the concept of stranded capacity: capacity that exists within a data center but cannot be effectively used to support productive computing workloads.

We developed a data-driven estimation model to assess the potential range of stranded capacity using publicly available industry data and key infrastructure variables such as facility size, utilization, PUE and cooling configuration.

The project combines data collection, web scraping, API integrations and ETL processes to bring together information from different sources and support the estimation model.

Rather than providing a single precise value, the model estimates a range of potential stranded capacity. This approach helps illustrate the scale of the problem and identify opportunities to improve resource utilization and reduce energy waste.

Technologies

Python Pandas SQL ETL APIs Web Scraping Data Visualization Dashboard

Telecom Churn Analysis

A Business Intelligence project focused on analyzing customer churn, identifying key patterns and measuring the financial impact of customer cancellations.



Description

This project analyzes customer churn in a telecommunications company to understand the main factors associated with customer cancellations and quantify their impact on revenue.

The project follows a complete data analytics workflow, starting with data generation and preparation in Python, followed by data storage and modeling in SQL Server, and ending with an interactive Power BI dashboard.

The data preparation process includes missing value treatment, data validation and transformation using Pandas and NumPy. More than 1,500 transactional records were generated to simulate the telecommunications environment.

A Star Schema was implemented in SQL Server, using primary and foreign keys to organize the data into fact and dimension tables and support analytical queries.

The resulting model was connected to Power BI, where DAX measures and Filter Context were used to create dynamic KPIs and interactive visualizations.

The dashboard focuses on metrics such as Churn Rate, number of churned customers and Revenue Lost, allowing users to explore customer behavior and understand the financial impact of cancellations.

Technologies

Python Pandas NumPy SQL Server Power BI DAX Power Query

Technical Architecture

Data Processing: Python scripts for data generation, cleaning and preparation.

Storage & Modeling: SQL Server with a Star Schema designed for analytical queries.

Business Intelligence: Power BI dashboard with DAX measures, dynamic KPIs and interactive filters.
